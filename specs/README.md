# Specs

This directory records delivered implementation slices and durable technical decisions.

Rules for future iterations:

1. Add or update a markdown file here when a slice lands.
2. Record what was actually implemented, not only what was planned.
3. Capture constraints and follow-up implications discovered during the work.
4. Keep design docs in `docs/` as the broader product spec.
5. Keep `specs/` as the implementation history and short-form technical record.
